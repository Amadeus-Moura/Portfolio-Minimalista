## 🎯 Sobre o Projeto

Este é o **Portfólio Profissional Minimalista** de **Amadeus Moura**, concebido com estética contemporânea de alto padrão (*dark minimalism*, tipografia cirúrgica, micro-interações táteis e alta densidade de informação técnica).

Diferente da versão gamificada com temática de anime ([Portfólio SAO](https://Amadeus-Moura.github.io/Portfolio-Gameficado/)), este projeto foi desenhado sob medida para **recrutadores técnicos, Tech Leads e diretores de engenharia**, destacando projetos em produção contínua, liderança arquitetural e rigor técnico.

---

## 🚀 Principais Funcionalidades

- **Design Dark Minimalist de Alta Performance:** Construído com React 19, Tailwind CSS v4 e paleta profunda (`#090a0f`) inspirada no Linear e Vercel.
- **Bento Grid & Indicador de Status Live:** Badges em tempo real indicando disponibilidade para estágio e vagas júnior.
- **Estudos de Caso Aprofundados (Modais Técnicos):** Cada projeto conta com um estudo de caso detalhado abordando o desafio real, a solução de engenharia, métricas e decisões arquiteturais.
- **Terminal Interativo de Infraestrutura:** Exibe o status ao vivo das instâncias OCI e containers Docker rodando 24/7.
- **Paleta de Comandos (`Ctrl + K` / `Cmd + K`):** Navegação instantânea por teclado entre seções, estudos de caso e canais de contato.
- **Visualizador de Currículo Executivo Integrado:** Modal pronto para leitura rápida com recurso de **cópia direta em texto puro** e botão para **imprimir ou exportar em PDF formatado**.
- **Comunicação em 1 Clique:** Botões para cópia com efeito visual de confete de e-mail e telefone, além de gerador automático de mensagens diretas no WhatsApp.
- **Ponte para o Portfólio Gamificado (Modo SAO):** Banner e badges elegantes permitindo alternar para a experiência imersiva de RPG a qualquer momento.

## 💻 Como Rodar Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/Amadeus-Moura/portfolio-minimalista.git

# 2. Acesse a pasta do projeto
cd portfolio-minimalista

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```

Abra `http://localhost:5173` no seu navegador.

---

## 📦 Como Gerar a Build de Produção

```bash
npm run build
```

Os arquivos estáticos otimizados serão gerados na pasta `dist/`, prontos para deploy direto no **GitHub Pages**, **Vercel**, **Netlify** ou qualquer servidor web Nginx/Apache.
